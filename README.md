# Portfolio

A UX/UI portfolio built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `app/` — routes (`/`, `/work`, `/work/[slug]`, `/about`, `/contact`)
- `components/` — shared UI, organized by concern (e.g. `layout/`)
- `lib/` — typed data and site configuration (case studies, nav links)
